**污水监测 · 开发切片与范围**

用户已确认增加“采样点、采样、检测结果、趋势研判”，不是污水处理设备与工艺运行管理。本模块作为独立组织业务接入清源，采样点可登记污水处理厂及汇水范围，与现有人员、案件和证物数据分离。

| 页面 | 已实现 |
| --- | --- |
| 采样点 | 编号、名称、区域、污水处理厂、汇水范围；组织内编号唯一；启用/停用及原因，版本冲突保护 |
| 采样记录 | 样本编号、点位、北京时间、瞬时/混合采样方式、采样人、可选日流量、质量状态和说明；存疑样本须说明原因，禁止从已停用点位新增采样 |
| 检测结果 | 原报告指标、实验室、方法、报告编号/版本、检出状态、浓度/定量限及说明；统一 ng/L，不隐式转换来源单位 |
| 修订与复核 | 录入人可修订待复核/退回记录；另一名本组织账号确认或退回；已复核数据禁止直接覆盖；每次录入/修订/复核保留完整快照与审计 |
| 趋势研判 | 按点位、指标、实验室、检测方法、采样方式和日期查询，图表+完整数值表；仅质量正常、已复核数据；每样本按录入时间取当前查询口径最近一条已复核记录 |

所有列表支持服务端分页与查询，沿用统一宽度和页面留白、会话取消及旧响应保护。下拉框先加载最近100个点位/样本；更早记录可通过对应台账搜索、分页并选择，不静默截断整个业务库。

**数据与研判边界**

- “定量检出”须填写正浓度；提供定量限时，定量浓度不得低于该值。低于定量限须填写定量限，未检出/低于定量限的浓度保持空值，不能填零。不同单位的原报告须先按经确认的规则换算，页面不会猜测单位。
- 同一样本、指标、实验室及报告编号/版本不重复登记；不同实验室的相同编号分别保留，趋势也按实验室分别查看。
- 原始浓度和日流量采用六位小数定点存储，SQLite 使用精确十进制文本、PostgreSQL 使用 NUMERIC(20,6)。这只是技术存储范围，不意味着检测方法具有六位小数的测量精度。图表使用浮点仅作视觉坐标，数值表保留原始十进制结果。
- 本轮趋势展示浓度变化，不计算排放负荷、区域消费量、吸毒人数、排名或自动异常阈值。日流量作为来源信息保留；混合采样覆盖时段、降雨/稀释、实验室方法版本和定量限变化仍需人工核对。选择相同过滤条件不保证样本具有相同代表性。
- 群体监测信号不是个人行为判断，也不自动创建案件、人员风险标签或执法结论。未检出/低于定量限不按零绘图，断开连接；样本质量存疑不会进入趋势。
- 正式岗位权限、采样标准与频次、实验室质量控制、检测项目字典、报告更正/撤回和档案保留需业务确认。本轮采用与既有模块一致的开发用组织隔离及不同账号复核，不能当作正式签发认证。
- 当前无附件上传、Excel/实验室接口导入、自动仪器对接、地图、规范化消费量模型或污染设施运维。这些需分别确认输入契约、授权、质量规则和验收数据后扩展。

**迁移与运行**

新增 `0019`，只建立四张独立表与索引，不修改现有业务数据；标记为本地启动可自动执行。现有库已到 `0018` 时，`python start.py` 会先备份再升级；未通过 `0017` 的库仍需先执行 `python migrate.py`。离线部署继续运行独立 migrate 任务，该任务同步为新表授予明确权限；采样记录和结果事件仅允许追加。

操作流程：登记点位 → 登记样本 → 录入结果草稿 → 另一账号核对/退回 → 按固定口径查询趋势。退回后原录入人修订重新进入待复核；已复核结果如需进一步更正，应使用原报告明确的新版本编号登记，历史保留。本轮没有正式撤回已复核结果的流程，错误结果不得用于真实业务，应先确认更正规则。

**验证**

使用虚构数据验证组织隔离、编号冲突、幂等、停用点位、检出/空值/定量限校验、录入/退回/修订/不同账号复核、历史快照、审计失败回滚、同口径趋势过滤及日期范围。浏览器覆盖点位—采样—检测—切换账号复核—趋势—跨组织不可见；PostgreSQL 专项覆盖精确数值与复核竞争。迁移验证包含全新安装、升级及模型一致性，未迁移现有用户数据库。

已完成后端全量131项、另外的0018→0019真实备份升级/模型一致性与单位/时区2个专项；前端35项回归及类型检查/构建通过，4条浏览器端到端通过（含污水闭环及原有流程）。正式采样质量与业务验收仍需在批准环境进行。

应用镜像构建通过，构建后部署入口的4条浏览器流程也通过，包含新增污水闭环。验证镜像使用合成 SQLite，PostgreSQL 存储/迁移与复核竞争由独立实例测试验证；不等于目标机器的正式联调验收。

背景参考：[EUDA 污水分析与毒品研究](https://www.euda.europa.eu/publications/pods/waste-water-analysis_en)。该机构将污水分析用于群体层面的监测，同时明确其代表性、回算方法和人口估计等限制；资料用于解释业务方向，不替代本地采样、检测及审批规范。
