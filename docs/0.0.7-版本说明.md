# 清源 Wellspring 0.0.7 版本说明

## 二、界面名称与兼容

不再以“草稿”统称不同业务资料，统一如下；状态仍按实际办理进度显示。

| 领域 | 界面名称/状态 | 保持的边界 |
| --- | --- | --- |
| 案件 | 案件记录、已登记；保存案件 | 登记与来源关联不代表正式立案或审批完成 |
| 人员 | 人员档案；未核验/已核验等实际状态；保存档案 | 姓名、旧档案及候选关系不自动认定身份 |

## 三、配置与接口

### 离线高德底图

底图须由部署方独立提供，放在源码之外；`WELLSPRING_MAP_TILE_DIR` 指向数字层级目录的上一级。例如文件为 `E:/wellspring-data/MapTiles/4/13/6/tile.png`，根路径填写 `E:/wellspring-data/MapTiles`。

```dotenv
WELLSPRING_MAP_TILE_DIR=E:/wellspring-data/MapTiles
WELLSPRING_MAP_ATTRIBUTION=按底图提供方要求填写署名
WELLSPRING_MAP_TILE_CRS=GCJ02
WELLSPRING_MAP_MIN_ZOOM=0
WELLSPRING_MAP_MAX_ZOOM=16
WELLSPRING_MAP_CENTER=120.301663,31.574729
WELLSPRING_MAP_INITIAL_ZOOM=13
```

初始中心使用**底图原生经纬度**，手工业务坐标输入仍为 WGS84；地图选点自动近似换算后须人工核对。`GCJ02` 只应给保留原始高德坐标的底图使用，不是把旧业务坐标直接改成高德坐标。`coordtransform@2.1.2` 固定于 npm 锁文件，运行时不调用公网坐标接口。

目录两种格式优先读取平铺 `y.png`，不存在时查找嵌套 `y/tile.png`。保留会话认证、根目录限制、有效 XYZ 索引和单文件 2MB 预算；不可读/格式错误/缺失瓦片可控返回，缺少覆盖的范围显示坐标网格。默认缩放和中心可配置，超出支持范围或错误坐标系配置返回 `MAP_CONFIG_INVALID`。

Compose 增加 `MAP_TILE_CRS`、`MAP_MIN_ZOOM`、`MAP_MAX_ZOOM`、`MAP_CENTER`、`MAP_INITIAL_ZOOM` 的对应传入项，底图仍通过只读目录/卷提供。示例默认是 WGS84；使用 GCJ02 时中心也必须同步切换成原生值。实际 `.env`、底图、密钥、数据库、浏览器截图和验证报告不放入 Git 或源码包。

本机已使用用户提供的原生高德 PNG 瓦片进行实际读取、显示和合成点位叠加/点选验证；不等于全覆盖、实地定位精度、底图授权或目标机验收。

### 审计查询

- `GET /api/audit/mine` 增加 `action`（中文名称或稳定代码）、`object_id`、`start_date`、`end_date`；仅匹配本人历史，不因组织调整丢弃本人旧记录，也不能读取他人历史。
- `POST /api/admin/audit/search` 沿用超级管理员和账号/动作范围校验，操作名称支持中文检索；两接口返回项新增 `action_name`，原始 `action` 保留兼容。
- 两接口的 `page_size` 默认值由 20 改为 15，显式值仍接受 1—100。日期按 Asia/Shanghai 自然日匹配，结束日期包含当天整天；非法或倒置日期拒绝，关键词中的 `%` 等按字面匹配。
- 中文目录涵盖当前及历史动作，未知历史代码显示“其他操作”；不猜测历史行为，不改写动作代码或审计流水。查询条件不作为业务原文写入审计。

AI 弹窗仍调用既有 `/api/ai/runs` 和状态接口：只提交统计周期，服务端重新汇总当前获准模块。发送确认、主机允许名单、幂等、并发限制、执行/保存前授权复核与纯文本输出保持；结果未知时保留同一提交键及原周期，取消后迟到状态不得覆盖取消结果。无新增权限代码或免授权入口。

## 四、版本升级与制品

产品包/锁文件、后端 API/OpenAPI、Compose 默认应用镜像标签和两份部署环境示例统一为 `0.0.7`，方案文档 v2.5.0 和开发规范版本单独管理。

1. 停止旧进程，备份数据库、代码、配置及密钥目录/卷；底图独立保管，不放入应用镜像。
2. 安装锁定依赖：Python 开发环境使用 `--require-hashes -r backend/requirements-dev.lock`，前端进入 `frontend` 执行 `npm ci`。本版新增的坐标库随 npm 锁安装，无需公网地图服务。
3. 已在 `0.0.6` / `0028` 的库无需新增 DDL；使用根目录 `python migrate.py --check` 核查结构即可。启动时沿用既有版本检查。从更早版本升级需运行 `python migrate.py`，若路径包含 **`0026` 证物八表删除**，仍须先核对备份、按显式迁移规则处理，不能因本版无新增迁移而跳过旧风险。
4. 重启 `python start.py` 加载本机配置和新代码。浏览器刷新后核对地图、筛选、中文审计/15条分页、弹窗和 AI 功能；本版不修改本机数据库中的既有坐标或业务记录。
5. 容器目标需重新构建、核验 `wellspring/app:0.0.7` 并加载正确配置；改变默认标签不会更新旧镜像或容器。生产平台联调与完整恢复演练仍按[离线部署说明](../deploy/offline/README.md)执行。

源码归档为 `releases/wellspring-0.0.7-source.zip` 及 `.zip.sha256`，按允许列表打包源码、文档、迁移、锁和测试，排除本机数据、凭据、依赖目录及构建/验证输出。脚本拒绝覆盖同版本制品，旧版本包保持。此次请求完成版本和文档整理，未自动创建 Git 提交/标签。
