## 个人开发启动前

- [ ] 复制并检查环境变量示例，不把真实密钥写入仓库。
- [ ] 从空目录安装后端依赖、执行迁移、创建开发账号。
- [ ] 从空目录执行 `npm ci` 和 `npm run build`。
- [ ] 用虚构数据完成登录、案件、证物和分样流程。
- [ ] 删除或隔离旧开发数据库后重复执行初始化，确认流程可重建。
- [ ] 记录当前依赖版本和异常警告。
