## 使用规则

1. 先阅读 00、01 和 07，再开始新的业务域开发。
2. 每个功能完成后同步更新数据字典、接口契约、测试矩阵和更新日志中受影响的部分。
3. 业务、权限、法律、生产环境和真实数据事项没有依据时，保留“待确认”，不要自行填写成已确定值。
4. 个人开发阶段可以用自己的决策记录替代多人签字，但不能替代安全边界、测试和数据一致性验证。
