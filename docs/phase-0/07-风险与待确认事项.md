# 07 风险与待确认事项

## 当前阻断风险

| 风险 | 影响 | 当前处理 | 解除条件 |
|---|---|---|---|
| 权限模型仅为组织过滤 | 可能无法满足生产越权防护 | 仅使用虚构数据开发 | 完成角色／字段／专案矩阵、RLS 和反向测试 |
| 证物流程不完整 | 不能用于正式账物管理 | 只验证初始登记和分样 | 完成全生命周期状态、审批、流水和验收案例 |
| API 非正式契约 | 前后端未来可能不兼容 | 维护开发接口草案 | 冻结 `/api/v1`、OpenAPI、错误码、分页和幂等 |
| 生产环境未验证 | 无法承诺部署、恢复和性能 | 使用本地 SQLite | 目标 PostgreSQL、对象存储、备份和离线安装通过 |
| 真实数据边界未审批 | 存在泄露和违规风险 | 禁止真实数据进入本地 | 完成数据分级、授权和环境审批 |

## 待确认但不阻塞个人 MVP

- 生产身份平台和账号生命周期。
- 正式组织／辖区／专案授权。
- 精度、提醒、保留和法律状态规则。
- OCR／LLM 模型、文书范围、评测阈值和算力。
- 性能、容量、RPO／RTO 和监控阈值。
- 对象存储、跨网交换和正式部署拓扑。

## 决策原则

- 没有依据的规则不写成硬编码。
- 没有授权的真实数据不进入开发环境。
- 不能验证的能力标记为“开发验证”或“待确认”。
- 风险影响权限、账实、正式事实或数据泄露时，停止扩展该能力，先补验证。
