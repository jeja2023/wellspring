## 已作出的开发决策

| 主题 | 当前决策 | 依据／限制 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite | 与总体方案一致；使用现有前端工程 |
| 后端 | FastAPI + SQLAlchemy 2.x + Alembic | 与总体方案一致；当前为模块化最小切片 |
| 数据库 | SQLite 仅用于本地开发；目标为 PostgreSQL | PostgreSQL 版本、RLS、备份和恢复尚未在目标环境验证 |
| 会话 | 当前为服务端短期 Bearer 会话 | 生产认证方式、撤权窗口和统一身份接入待确认 |
| 文件 | 当前未接入生产对象存储 | 真实文件、导出和附件流程不得启用 |
| 后台任务 | 当前未形成 Worker 生产底座 | OCR、导入、导出等长任务不得伪装成同步完成 |
| AI／OCR | 当前未启用 | 文书类型、样本、模型、算力和评测阈值待确认 |
| API | 当前 `/api` 为开发接口 | 正式版本应迁移到 `/api/v1` 并冻结 OpenAPI |
| 数据 | 仅使用虚构开发数据 | 禁止复制真实案件、人员、证物或文书到本地 |
