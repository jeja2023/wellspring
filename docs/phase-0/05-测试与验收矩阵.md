## 每个新功能的最小用例

| 类别 | 至少覆盖 |
|---|---|
| 正常 | 合法输入、最小值、常规权限、成功反馈 |
| 参数 | 缺失、空字符串、超长、非法枚举、精度和边界值 |
| 权限 | 未登录、跨组织、禁用账号、过期会话、直接调用接口 |
| 一致性 | 重复请求、并发修改、事务回滚、版本冲突、失败重试 |
| 页面 | 加载、空、无结果、失败、无权、成功、部分成功、键盘焦点 |
| 数据 | 来源、状态、单位、时间、精度、流水和审计可追溯 |

## 当前切片重点

- 组织 A 创建的案件不能被组织 B 列出或作为证物关联。
- 同一组织内重复案件编号返回冲突，不覆盖原记录。
- 初始 100 克分样 10 克后，原物 90 克、检材 10 克，不能统计成 110 克。
- 分样超过余额、超出六位小数和无效案件 ID 必须失败且不留下半提交。
- 退出后会话不能继续读取业务接口。

## 通过标准

个人开发功能只有在正常、失败、权限反向和必要一致性测试通过后，才可标记为 `0.0.x` 开发验证完成；任何越权、历史流水丢失、重复扣减或密钥泄露问题都属于阻断问题。
