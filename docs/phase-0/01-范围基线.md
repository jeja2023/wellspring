# 01 范围基线

## 当前可运行切片

| 功能 | 状态 | 说明 |
|---|---|---|
| 开发账号和登录 | 已实现 | 本地账号、短期服务端会话；仅用于开发验证 |
| 退出和会话撤销 | 已实现 | 当前用户会话全部撤销；生产撤权策略待确认 |
| 组织范围过滤 | 已实现 | 服务端按账号组织过滤；不等同于生产角色／字段／专案授权 |
| 案件草稿 | 已实现 | 创建、服务端分页、名称／编号筛选及稳定排序 |
| 案件关系 | 部分实现（0.0.4 开发验证） | 同组织案件关联与协办，支持撤销；并案、派生、拆分尚未实现 |
| 证物初始登记 | 已实现 | 记录案件、名称、初始重量和初始流水 |
| 证物分样 | 已实现 | 父对象条件扣减、子对象增加、同一操作 ID 双向流水 |
| 流水查看 | 已实现 | 查看指定证物的重量事件 |
| 证物保管交接 | 部分实现（0.0.4 开发验证） | 开发基线、指定接收人确认／拒收；无实物封条核验或正式审批 |
| 证物盘点观测 | 部分实现（0.0.4 开发验证） | 保存实测和差异，不改变余额；支持开发用调查说明及独立复核，正式审批和调整未实现 |
| 人员最小草稿 | 部分实现（0.0.4 开发验证） | 名称、来源及未核验状态；可记录同组织案件的待核查候选，不自动去重或确认身份 |
| 情报线索 | 部分实现（开发验证） | 线索草稿、人工核验、简化核查工单及同组织案件关联已实现开发验证；精确碰撞、人员／证物关联和授权检索尚未实现 |
| 数据导入 | 部分实现（0.0.4 开发验证） | 虚构案件 CSV 可暂存并确认新增草稿；正式 Excel 导入与更新未实现 |
| 权限审计 | 部分实现（0.0.4 开发验证） | 只可查看本人本组织本地审计；角色与审计中心未实现 |
| 智能解析 | 未实现 | 仅显示本地模型未接入状态，不能上传或解析文书 |
| 审计基础记录 | 已实现 | 关键开发操作写入本地审计表；不代表受保护审计已完成 |

## 下一迭代建议（0.0.x）

1. 拆分集中式 `frontend/src/App.vue`，建立共享 UI、API 和业务域目录。
2. 已完成案件、证物和流水列表的服务端分页；继续完善角色及统计权限。
3. 已建立开发接口错误码、`request_id` 和输入错误映射；继续完善 `/api/v1` 迁移计划。
4. 已为三个写操作增加幂等及分样版本校验；继续验证 PostgreSQL 并发及跨页重试。
5. 在目标 PostgreSQL 环境验证迁移、非特权账号、并发和 RLS 原型。
6. 为证物交接、送检、消耗、退样、盘点、销毁先完成状态设计和测试，再编码。
7. 依据 [情报线索范围草案](09-情报与线索范围草案.md)，准备线索、核查工单、碰撞和授权检索；独立情报管理扩展待确认。

## 暂不纳入当前个人 MVP

- 真实数据、正式身份平台、正式生产网络和跨网交换。
- 完整的法律状态自动计算、提醒规则和正式审批流程。
- 生产对象存储、正式导出、完整附件保留和独立审计归集。
- OCR／LLM 生产试点、Embedding、Reranker、关系图谱和未经评测的自动推断。
- 历史数据迁移、全量导入、用户培训和生产上线承诺。

## 非目标

当前版本不替代警综、部级或法定业务系统；不自动确认法律事实；不以页面显示代替服务端授权；不把示例数据、测试结果或原型视为生产能力。
