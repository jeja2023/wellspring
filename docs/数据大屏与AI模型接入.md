# 数据大屏与 AI 模型接入

完整版本范围、发布验证与升级方式见 [0.0.6 版本说明](0.0.6-版本说明.md)。

本功能归入 `0.0.6` 开发验证版，新增迁移 `0022`、`0023`。所有验证使用合成业务数据和隔离模拟模型，尚未接入用户实际模型服务。

## 页面入口

- **数据大屏**：位于“工作台”之后，显示当前组织的接警、案件、业务模型、线索、人员和污水采样总量及期间新增；只展示当前角色具有查询权限的模块。
- **智能研判**：保留在“操作记录”之前。支持文本摘要、要素提取、资料问答、统计解读、个人生成历史、取消、复制和下载草稿。
- **配置模型服务**：位于“智能研判”页面顶部，仅超级管理员可见；以共享弹窗设置接口根地址、API Key、模型 ID、超时、输出长度、启停和连接检查，不再单设主菜单。

页面沿用现有卡片、输入框、表格、弹窗和分页样式，顶部栏统一显示当前页名。

## 大屏口径

总量和各状态分布为当前组织全量；7/30/90 天只影响期间新增和日趋势。新增按记录创建时间、北京时间统计，接警隐藏记录不计入。污水趋势在这里统计采样记录新增量，不把不同检测口径的浓度相加或混合；浓度研判继续使用污水监测的同口径趋势。

“数据大屏查询”不扩大业务数据范围。即使是超级管理员，大屏也只统计其当前所属组织；没有相应业务模块查询权限时，该模块不返回零值或明细，而是省略。大屏不返回案件标题、人员信息、证物标签或接警原文；接警类型分布仅展示分类标签和计数。

可手动刷新或启用每分钟刷新，浏览器页面隐藏时暂停自动刷新。读取失败时显示上次成功数据并提示，成功刷新才替换统计；支持全屏展示和每日数据表。页面中的“更新时间”是本次统计快照时间，不代表后台实时流。

## 模型服务配置

1. 先备份并升级数据库到 `0023`。本地通过 `python start.py` 的受控迁移或显式 `python migrate.py`；离线环境仍使用独立 migrate 任务。
2. 在服务端设置允许连接的主机。默认仅允许 `localhost,127.0.0.1,::1,host.docker.internal`。使用内网模型时，把实际主机加入 `WELLSPRING_AI_ALLOWED_HOSTS`；填写主机名或 IP，不含协议、路径和端口，不支持通配符。
3. 若服务需要鉴权，可在“智能研判 → 配置模型服务”弹窗的 API Key 输入框填写。保存时密钥写入服务端受控目录，数据库只保存随机引用，API 响应不回显原值；浏览器不长期保存密钥。输入框留空表示保留现有 Key。“清除密钥”保存后停止使用密钥并覆盖环境回退；“使用环境配置”保存后恢复读取 `WELLSPRING_AI_API_KEY` 或 `WELLSPRING_AI_API_KEY_FILE`。无鉴权本地模型可不配置 Key。环境与文件方式仍二选一，文件为 UTF-8 无 BOM 单行，可带一个 LF/CRLF 结尾。
4. 页面 Key 默认保存在 `backend/.secrets/`，可通过 `WELLSPRING_AI_SECRET_DIR` 指定目录；应限制目录访问并与数据库配置一并备份。替换/清除配置成功后清理旧引用文件，写入失败或版本冲突时删除未生效的新文件。重启后端以加载环境配置。`start.py` 会从根目录 `.env` 读取上述配置，进程环境优先；直接运行 Uvicorn 时自行设置环境，不自动读取 `.env`。示例文件中不填写真实密钥。
5. 超级管理员进入“智能研判”，点击“配置模型服务”打开弹窗，填写接口根地址，例如 `http://127.0.0.1:8001/v1`，填写 API Key（需要时），点击“获取模型列表”，在“可用模型 ID”中选择。只有一个 ID 且当前为空时自动填入，也可手动填写模型名称。点击“测试模型连接”后再启用并保存。获取列表/测试使用当前表单，不需要先保存，且不持久化输入 Key；列表接口不受支持时仍可手动填写 ID 并测试。不要把 `/chat/completions` 填入根地址，不在 URL 中嵌入账号、密钥或查询参数。

本地 PowerShell 环境示例（将主机、地址和模型换成真实配置）：

```powershell
$env:WELLSPRING_AI_ALLOWED_HOSTS = '127.0.0.1,model.internal'
$env:WELLSPRING_AI_API_KEY_FILE = 'C:/wellspring/secrets/ai_api_key'
python start.py
```

连接检查只发送固定测试文字并确认返回文本，不读取业务资料。模型列表使用同一个 API Key 请求 `GET {base_url}/models`，按 `data[].id` 读取、去重和排序，上限 500 项；接口格式依据 [OpenAI List models 官方参考](https://developers.openai.com/api/reference/resources/models/methods/list)。列表可见不等于支持文本生成，选定后需执行连接测试。检查失败会显示经过整理的鉴权、地址、连接、超时或返回格式错误；不回传模型服务原始报错。模型可使用 `max_tokens` 或 `max_completion_tokens` 输出长度参数，按实际服务选择。

采用 `POST {base_url}/chat/completions`，请求包含 model、system/user messages、stream=false 和所选长度参数，返回读取 choices[0].message.content；兼容格式依据 [OpenAI Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。不同兼容服务的能力仍需实测；当前没有 Responses、工具调用、图片、语音或流式生成协议适配。

## Docker 环境

Compose 用独立 `wellspring_ai_secrets` 持久卷保存页面 Key（应用内 `/app/.secrets`），应用目录以运行用户拥有并限制权限；需备份该卷和数据库引用，单独恢复数据库不能找回对应 Key。Compose 的模型允许名单来自包外环境变量 `AI_ALLOWED_HOSTS`，可通过 `AI_API_KEY` 向应用进程注入密钥。若使用文件密钥，通过包外 Compose override 仅向 app 单独挂载模型密钥，设置 `WELLSPRING_AI_API_KEY_FILE`，同时移除 `WELLSPRING_AI_API_KEY` 值。

容器中的 `127.0.0.1` 是容器自身。模型在 Windows 宿主机时可使用 `host.docker.internal`；在相邻模型容器时应连接经批准的共享网络。默认数据库网络是 `internal: true`，不会因配置模型 URL 自动开放外部网络；访问其他内网/外部服务需另行配置批准的应用网络路由，数据库仍不对外暴露。Compose 不会自动启动模型或下载权重。

## 权限与输入

| 权限 | 用途 |
| --- | --- |
| `dashboard.read` | 查看综合统计；还需对应业务模块 `.read` 才能看到该模块 |
| `ai.read` | 查看模型状态和本人当前组织的任务/草稿 |
| `ai.generate` | 提交模型任务；需同时授予 `ai.read` |
| `system.ai` | 模型配置和连接检查，仅超级管理员保留 |

`0022` 给旧“业务用户”兼容角色补充大屏和 AI 查询入口，**不会自动授予 `ai.generate`**；自定义角色由管理员明确授权。超级管理员可直接配置和使用。角色/组织/会话仍在服务端验证，不能靠前端菜单绕过。

每次提交前需明确勾选发送确认。文本任务只发送当前输入的原文和补充要求；统计解读由服务端重新汇总授权范围数据，不信任浏览器传来的统计，也不自动抓取业务全文。统计预览和实际提交时间可能不同，以任务提交时统计为准。模型输出始终作为纯文本显示，不执行其中 HTML/脚本，不直接写入业务记录。

输入原文最多 20,000 字符、补充要求 2,000 字符；输出最多 64,000 字符，接收体最多 1 MiB，超时 5–120 秒，输出 Token 上限可配 128–8192。AI 推断可能有误，业务判断仍需人工核验；当前没有 PDF/Word 上传、OCR 或自动建案。

## 任务与历史

任务提交采用幂等键并立即返回任务编号；页面轮询状态，不长时间挂起页面请求。历史仅本人在当前组织可见，超级管理员也不能借本人历史接口读取其他用户输出。原文不落任务表，只保留输入长度、摘要校验值、模型/配置版本、状态、耗时和模型输出；模型输出可能复述输入，因此生成历史仍需遵循业务数据保管要求。

每账号最多一个活动任务、每小时最多 30 个，单进程最多 4 个；没有自动重试模型调用。服务重启会中断进程内任务，超过 5 分钟的未完成任务在下次读取/提交时标记中断，不自动重新发送。取消是停止接收并保存后续输出，不能保证上游模型已经停止计算；超时也可能已发送输入。任务执行前及保存结果前再次检查账号、组织、权限和会话，撤权后的迟到输出不保留。

这是单进程的有界后台执行，尚不是跨节点持久任务队列。没有自动删除任务历史的策略，也没有后台扫描/定期报告；生产保留期、模型部署、网络保护、模型质量和输出核验流程需另外确定。

## 验证

使用回环地址的隔离模拟服务检查兼容请求、连接检查、摘要/统计生成、失败响应、幂等、防越权、输出文本转义和历史；补充取消/撤权迟到输出、总超时、拒绝重定向、北京时间跨日及允许名单/密钥文件验证。

本轮结果：后端全量 151 项通过、13 项需独立 PostgreSQL 连接的集成用例跳过；前端 38 项、浏览器 12 项、类型检查和生产构建通过。全新 SQLite 和 `0021 → 0022` 升级/Alembic check 通过，核对模型默认关闭且未自动授予生成权限。`pip check`、锁文件复用校验、文档本地链接和差异格式检查通过。新接口运行期间的最后授权/响应读取调整另做专项验证。

验证资料在本地 `releases/ai-dashboard-validation/`，浏览器截图与跟踪在 `frontend/test-results/`；均使用合成数据，不纳入 Git。未升级用户数据库、未重新构建或部署镜像，未获得新的远程 CI 结果。不把模拟模型结果表述成实际模型质量、性能或生产验收。

本轮 API Key/自动发现增强新增 `0023`（仅加入服务端密钥引用列），不自动读取或迁移真实 Key；使用合成 Key 验证未保存探测、保存/保留/清除/环境回退、响应不回显、鉴权失败和模型 ID 去重。相关专项 13 项后端与 2 条浏览器流程通过，类型检查和构建通过；SQLite 全新/`0022 → 0023` 与模型一致性检查另行核对。

界面统一命名为“智能研判”，原“智能解析”及独立“模型服务”导航缓存会恢复到该页面。配置保存成功后关闭弹窗并刷新服务状态，保留当前待处理文本；重新确认发送后再生成。弹窗提交期间阻止关闭，失败保留输入，可取消或按 Escape 退出并恢复焦点。权限代码与 API 路径保持兼容，无新增数据库迁移。
