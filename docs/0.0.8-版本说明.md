# 清源 Wellspring 0.0.8 版本说明

版本日期：2026-11-14。状态：**本地开发验证版本**。本版本在 `0.0.7` 与工作台窗口优化、测试数据工具基础上完成全站视觉令牌（Design Tokens）与多主题体系、顶栏合并账户菜单、登录页重构、数据大屏趋势/分布重设计及构建类型修复，数据库继续沿用 head `0028`，不新增数据库迁移或自动授权。

## 一、本次范围

| 模块 | 0.0.8 最终变化 |
| --- | --- |
| 设计令牌与多主题 | 新增 `frontend/src/styles/tokens.css` 样式令牌与 `theme.ts` 状态管理，并同步更新 `style.css` 及各业务模块样式；默认调整为明快「清朗浅白（light）」，提供「清朗浅白 / 柔雾天蓝（ocean）/ 柔和暗夜（dark）」三套切换方案及顶栏微调；移除舒适/紧凑布局切换与 `Ctrl+K` 命令面板 |
| 导航与共享组件 | 新增 `NavIcon.vue` 矢量图标、`StatusBadge.vue` 状态徽章、`ConfirmDialog.vue` 确认弹窗；支持侧栏折叠 |
| 顶栏账户合并 | 新增 `UserMenu.vue`，将顶栏右上角零散的用户组织/姓名/角色/改密/退出按钮合并为单一账户菜单胶囊，并同步更新 11 份浏览器回归测试中的退出交互路径 |
| 登录页重构 | 重绘左侧浅色天青蓝渐变背景与矢量水波/拓扑盾徽装饰；去除多处重复的「协同」「平台」冗余用语，统一为 `清源 / WELLSPRING` 标识与简洁说明；右下角「清源工作台」旁接入从 `package.json` 构建注入的版本徽标（`v0.0.8`） |
| 数据大屏趋势图 | 默认改版为 3×2「分项趋势」独立刻度小图矩阵（支持悬停跨卡同步读数与点击单模块宽幅聚焦），保留「分项趋势 / 叠加对比」切换；在全模块叠加图中仅单模块或悬停系列渲染填充，其余线条降透明度防遮挡；将各模块切换芯片与「查看每日数据」上移至趋势图上方控制区；移除单独的浅色/暗黑大屏切换按钮 |
| 数据大屏分布区 | 底部统计区重构为对称 6 栅格布局（5 项时上排 2 张环形分布图 + 下排 3 张分段堆叠比例条，1100px/800px 自动适配），卡片展示 `合计 X 条` 徽标、百分比与空态虚线环提示 |
| 工作台与测试数据 | 纳入前期未归档的工作台窗口高度适配、固定表头表内滚动、四卡紧凑排版、名称/类型分列、移除底部快捷办理区，以及 `scripts/seed_demo_data.py` 虚构测试数据工具（参见[工作台与数据大屏](工作台与数据大屏.md)与[测试数据与演示账号](测试数据与演示账号.md)） |
| 构建与类型工程 | `vite.config.ts` 改用静态导入 `./package.json` 注入 `__APP_VERSION__`、以 `loadEnv(mode, '.', '')` 替代 `process.cwd()` 并移除 `node:fs`；新增 `src/vite-env.d.ts` 并在 `tsconfig.json` 开启 `resolveJsonModule` 且纳入 `vite.config.ts`，无 `@types/node` 依赖下消除 TypeScript 报错 |

## 二、版本与兼容边界

- 数据库迁移继续沿用 head `0028`，相对 `0.0.7` 无新增表结构、权限代码、接口路径或数据变更；已有 `0.0.7` / `0.0.6` 开发库无需运行额外迁移。
- 前端包/锁文件（`frontend/package.json`、`frontend/package-lock.json`）、后端 FastAPI 元数据（`backend/wellspring/main.py`）与离线部署默认镜像标签（`deploy/offline/compose.yaml`、`env.example`、`env.windows.example`、`deploy/offline/README.md`、`deploy/offline/WINDOWS.md`）统一更新为 `0.0.8`。
- `releases/wellspring-0.0.8-source.zip` 及 `.zip.sha256` 通过 `scripts/build_source_release.py` 按允许列表打包生成，不包含本机 `.env`、数据库、日志、`node_modules`、`.venv` 及截图输出。
- 本次已完成本地 Git `0.0.8` 提交与 `v0.0.8` 版本标签记录（沿用本机 Git 仓库管理规范）。
