# 清源 Wellspring 0.0.5 版本说明

版本日期：2026-11-11。产品版本 `0.0.5`，数据库迁移 head `0021`。本版本汇总 `0.0.4` 之后全部未发布变更，仍用于虚构数据的本地开发验证。方案文档 v2.5.0、开发规范版本和数据库迁移编号分别管理。

## 功能范围

| 范围 | 最终行为 |
| --- | --- |
| 接警信息与案件 | 独立接警 Excel 台账与案件草稿；明确新建/关联案件，保留来源快照和撤销历史，不自动认定立案 |
| 污水监测 | 点位、采样、检测、修订、不同账号复核及同口径趋势；不推算个人行为或吸毒人数 |
| 系统管理 | 用户、角色、权限、组织维护，本组织委派管理，密码重置/修改、会话撤销、版本条件更新及最后管理员保护 |
| 业务与数据正确性 | 会话隔离、乱序保护、分页失败保全、精确 SQLite 重量、完整详情编辑及幂等重放授权 |
| 导入与查询 | 可取消 Excel Worker、解压与字符预算、结构化行错误、摘要列表/完整详情分离、翻页复用统计 |
| 启动与交付 | 统一迁移命令、受控备份后自动迁移、可信离线校验、明确数据库运行权限、构建输入溯源及隔离恢复工具 |

完整变更分类见[更新日志](../更新日志.md)，系统使用与授权边界见[系统管理与权限](系统管理与权限.md)。

## 页面与导航

在拥有相应权限的账号下，业务导航顺序为：工作台 → 接警信息 → 案件管理 → 证物管理 → 情报线索 → 污水监测 → 人员档案 → **智能解析 → 操作记录**。其后为系统管理分组：用户管理、角色管理、权限管理、组织管理、系统日志。菜单继续按有效权限显示；智能解析仅显示未接入状态。

- 顶部栏统一显示页面名称，移除内容区重复标题、英文副标题和对应介绍块；详情分区和弹窗保留功能标题。
- 页面统一内容宽度、留白、卡片、输入框、按钮和表格样式；数据表格具有完整边框及跨页连续序号，共享分页右对齐。
- 新增与编辑统一弹窗；保存成功关闭，失败保留输入，提交时防止重复提交和关闭，支持键盘取消与焦点恢复。
- 用户表中的账号、所属组织和角色独立成列；角色表中的名称、代码和级别独立成列。数据单行显示，窄屏表格内横向滚动。
- 权限管理采用与其他管理页一致的单卡片布局：顶部角色/名称代码/模块筛选及仅看已选，下方按序号、业务模块、权限名称、权限代码、配置范围、授权状态分列；底部使用共享分页及常规保存/撤销操作区。筛选和翻页保留授权草稿，切换角色时处理未保存更改；缺少查询权限的无效组合不得保存。
- 案件 CSV 导入在“案件管理 → 批量导入 / 导入记录”，接警 Excel 导入在“接警信息”，不再单设“数据导入”主菜单。

## 版本与制品

前端 `package.json` 与锁文件、后端 FastAPI 元数据、Compose 默认应用标签和两份环境示例均为 `0.0.5`。历史更新日志、历史源码包和历史审查证据保持其原版本含义。

运行 `python scripts/build_source_release.py` 生成 `releases/wellspring-0.0.5-source.zip` 及 `.zip.sha256`，按允许列表收录源码、文档、锁文件和测试，不包含实际数据库、`.env`、密钥、虚拟环境或前端依赖目录。该源码包不是离线 Docker 镜像包；现有历史验证镜像不会因修改默认标签而升级，目标环境需重新构建并核验 `wellspring/app:0.0.5`。

## 数据库与升级

| 迁移 | 内容 |
| --- | --- |
| `0014` | 接警信息独立台账 |
| `0015` | 初始管理员标识 |
| `0016` | 系统运维组织 |
| `0017` | SQLite 精确重量与校验 |
| `0018` | 列表、审计、会话和工单查询索引 |
| `0019` | 污水监测模型 |
| `0020` | 接警与案件来源关系 |
| `0021` | 角色、账号管理、组织层级与管理互斥 |

1. 停止旧服务，核对数据库目标，备份代码、配置和数据库；先在隔离副本验证升级与恢复。
2. 安装锁定依赖：开发环境使用 `python -m pip install --require-hashes -r backend/requirements-dev.lock`，前端在 `frontend` 运行 `npm ci`。部署镜像使用运行依赖锁。
3. 在根目录运行 `python migrate.py` 至 `0021`；已经位于 `0021` 时无额外结构迁移。受控启动迁移仅执行已明确标记安全的迁移，遇到人工边界应核对后使用显式命令。离线部署继续使用独立 `migrate` 任务并重新应用运行角色权限。
4. 重新启动，检查 `/api/ready`、登录、授权菜单及接警/案件/证物/污水核心流程。不要将更新版本号视为已经更新运行中的旧进程或镜像。

`0017` 不能恢复历史浮点丢失精度，遇到异常重量会停止且禁止有损降级。`0021` 将旧普通账号纳入兼容业务角色，不自动授予系统管理权限。代码和旧数据库结构未承诺任意向后兼容，回退须恢复已验证的匹配备份。

## 已知边界

模块级授权不替代正式字段/专案/跨组织共享矩阵；RLS、统一认证、独立受保护审计、正式采样质量和审批、网络保护及目标环境验收仍需完成。进程级登录节流不覆盖多实例共享限流，幂等保留期没有擅自缩短。ExcelJS 按需加载包仍有体积提示；历史测试客户端存在弃用提示。完整生产离线发布继续遵循[版本发布流程](版本发布流程.md)和[离线部署说明](../deploy/offline/README.md)。
