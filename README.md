## 已实现的开发切片

- Vue 3 + TypeScript 工作界面，开发环境标识；本地命名账号、短期服务端会话及退出撤销。
- 当前组织内的案件草稿、服务端分页和筛选，以及案件关联／协办关系（不代表并案）；证物初始重量登记、分样、双向重量流水、盘点观测与调查说明复核，以及同组织单件保管交接验证（均不自动调整余额）。
- 人员最小草稿：仅保存名称、来源和未核验状态，可记录同组织案件的待核查候选关联；不进行身份核验或自动去重。
- 数据导入支持虚构案件 CSV 暂存、逐行核对及仅新增草稿的确认；权限审计提供本人审计记录查询；智能解析目前仅展示未接入状态。
- 开发验证用情报线索：草稿、组织内标题／来源与状态筛选、人工核验、核查工单、重分派、退回及独立复核，含处理事件与基础审计，并支持手动填写办理期限、工作台个人工单以及同组织案件关联／撤销。
- 组织范围由服务端账号决定，基础业务动作与本地审计同事务提交；分样采用数据库条件更新，防止余额不足。
- SQLAlchemy 数据模型与 Alembic 初始迁移，支持以 `DATABASE_URL` 指定 PostgreSQL；默认 SQLite 仅供开发。

## 本机运行

需要 Python 3.12、Node.js 和 npm。仅使用虚构数据。

### 首次安装

在 PowerShell 中执行一次：

```powershell
cd E:\wellspring\backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m wellspring.bootstrap

cd E:\wellspring\frontend
npm ci
```

创建开发账号时，按提示输入账号、组织和至少 12 位的密码。如果已有账号，无须重复执行 `bootstrap`。

### 一键启动

```powershell
cd E:\wellspring
python start.py
```

保持该终端窗口打开，访问 [http://127.0.0.1:5173](http://127.0.0.1:5173)；按 `Ctrl+C` 停止本次启动的前后端。前端支持 Vite 热更新；修改后端代码后需停止并重新运行启动脚本。

启动器不会自动安装依赖、修改数据库或终止已有服务。若提示数据库迁移未完成，请先在 `backend` 目录执行 `.\.venv\Scripts\python.exe -m alembic upgrade head`。若默认端口已被其他进程占用，先自行停止对应服务，或使用其他端口：

```powershell
python start.py --backend-port 8001 --frontend-port 5174
```

前端会自动代理到所指定的后端端口。访问令牌只保存在页面内存中；刷新页面需要重新登录。该启动器仅供本地开发，生产部署仍需单独设计。

运行检查：`cd backend; .\.venv\Scripts\python.exe -m pytest -q` 和 `.\.venv\Scripts\python.exe -m alembic check`；`cd frontend; npm test; npm run build`。GitHub Actions 工作流已提供，但仓库托管和分支保护尚未配置。

## 明确缺口及后续工作

使用新线索功能前，停止旧版后端并备份开发数据库，在 `backend` 目录执行 `.\.venv\Scripts\python.exe -m alembic upgrade head`（迁移至 `0013`），再重新启动前后端。启动器不会自动执行迁移。`0.0.1` 的列表由数组改为分页对象，案件／证物写接口要求 `Idempotency-Key`，分样还要求 `source_version`；旧 API 客户端需要同步调整。页面只在内存保留未确认请求的幂等键，刷新或退出后应先核对结果，不能盲目重发。

当前组织过滤只是开发用的最小边界，**不满足生产权限要求**。尚未实现岗位角色和字段权限、专案授权、PostgreSQL RLS、撤权窗口、登录限速、独立受保护审计和安全认证集成。没有生产部署、HTTPS、备份恢复、离线制品及供应链验收。

证物仅支持初始登记和分样；已为开发写接口增加幂等记录，但尚无正式岗位复核、实物交接、送检、消耗、退样、盘点差异正式审批及调整、销毁、附件或完整账实核对；不得据此保管实物或计算正式账目。线索工单仅具备开发验证的组织隔离和简化流程，尚无正式岗位权限、自动期限规则及跨区协作；案件派生／并案／拆分、人员身份核验及措施事件、精确碰撞、正式人员／证物关联、Excel 正式导入、文书 AI 解析和正式检索均未实现。页面上的未实现模块不代表已交付能力。
